# Python Robot Tutor

Статический учебный сайт для GitHub Pages. Цель - помочь новичку увидеть, как программа выполняется по шагам: строка кода, действие робота, изменение состояния, переменные и вывод.

Код ученика выполняется настоящим Python-интерпретатором в браузере через Pyodide. Команды робота подложены скрытой учебной библиотекой и доступны сразу как `go()`, `turn_right()`, `read_number()` и т.д.

## Учебный принцип

Стартовый код в уровнях - это заготовка, а не готовый ответ. Ученик должен предсказать выполнение, запустить код по шагам, дописать решение и объяснить, почему оно работает.

В новых семейных уровнях стартовый код может специально проходить первый пример, но ломаться на других входах. Это сделано намеренно: приложение показывает, что код, подобранный под пример, еще не является решением задачи.

Модель уровня:

```text
уровень = правило + семейство входов + проверки
```

Каждый семейный уровень показывает:

- что не меняется;
- что может измениться;
- видимый example;
- edge cases;
- generated cases;
- первый контрпример, который можно открыть через Replay fail.

## Что уже есть

- 17 базовых учебных уровней.
- 8 семейных уровней на обобщение решения.
- Редактор кода.
- Кнопки Run, Step, Reset, Starter.
- Кнопка Run all для проверки одного кода на нескольких входах.
- Replay fail для пошагового разбора контрпримера.
- Сетка с роботом, стенами, целью и предметами.
- Подсветка текущей строки в панели шагов.
- Панель переменных, ввода, вывода и трассы.
- Дружелюбные ошибки для частых ситуаций.
- Проверки результата.
- Скрытые тесты для уровней на ввод/вывод, чтобы ловить хардкодинг.

## Более хитрые семейные уровни

- `G5` - извилистый путь без развилок: нужен алгоритм с датчиками, а не маршрут по памяти.
- `G6` - сбор предметов на неизвестном пути: движение и проверка предметов должны работать вместе.
- `G7` - `input → вычисление → действие`: прочитать `n` и пройти `2 * n` клеток.
- `G8` - сумма до нуля: читать неизвестное количество чисел, пока не встретится `0`.

## Python и учебная библиотека

Ученик пишет настоящий Python. Учебная среда скрыто добавляет пакет `robot` и сразу импортирует основные команды в глобальную область:

```python
go()
go(3)
turn_left()
turn_right()
turn(180)
pick()
say("готово")
print(123)

if front_is_clear():
    go()
else:
    turn_right()

for i in range(4):
    go()

def turn_around():
    turn_right()
    turn_right()

x = read_number()
print(x + 1)
```

Можно также писать:

```python
from robot import go, at_goal

while not at_goal():
    go()
```

Поддерживается обычный Python-синтаксис: `while`, `for`, функции с параметрами, списки, словари, строки, арифметика, условия, импорт стандартных модулей и т.д. Среда перехватывает `print()` и показывает вывод в панели.

Важно: это учебная среда в браузере, не security-grade sandbox. Код выполняется на устройстве ученика, без backend-сервера.

## Локальный запуск

Можно просто открыть `index.html` в браузере.

Или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

Потом открыть:

```text
http://localhost:8000/robot_tutor_pages/
```

Если запускать сервер из папки `robot_tutor_pages`, адрес будет:

```text
http://localhost:8000/
```

## Деплой на GitHub Pages

После авторизации GitHub CLI:

```bash
gh auth refresh -h github.com
```

Можно создать репозиторий и включить Pages:

```bash
cd /Users/aleksei_shevkoplias/Documents/programming_lessons/robot_tutor_pages
git init
git add .
git commit -m "Add Python Robot Tutor"
gh repo create python-robot-tutor --public --source=. --remote=origin --push
gh api repos/AlekseiShevkoplias/python-robot-tutor/pages -X POST -f source.branch=main -f source.path=/
```

После включения сайт обычно появляется по адресу:
